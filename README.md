# 切面 · 故事与剪辑思维实验室

在线地址：<https://maylily1992.github.io/cutmind-story-lab/>

## 核心能力

- 每天从五个不同层面提供 5 个高阶叙事与剪辑技巧，并附机制、少见角度、微案例、练习、诊断问题和误用信号。
- 215 个术语与操作节点组成的“故事技术图谱”，先分为 **物、知、动、感、元** 五层，再细分为 13 个分支、39 个知识簇，并保留横向关系。
- 每个术语节点都可打开专页，查看底层机制、具体案例、迁移方法、失效条件、相关术语、大师方法与个人观影证据。
- 28 天高密度主线：每天 10 个图谱术语、5 个深技巧、1 位大师方法、1 个异闻与 1 个实剪实验。
- 44 位导演、剪辑师、编剧或理论家的形式签名与方法索引。
- 每天提供一个原创叙事谜题、创作案例、结构传统或跨学科模型，提取可迁移到剪辑的形式操作。
- 导入两个本地视频版本，自动扫描镜头切点并比较平均镜头长度、切点密度、节奏波动和最长镜头。
- 在时间线上记录具体剪辑判断，生成可交给 AI/Codex 的作品诊断包。
- 维护 16 维创作画像、未来自我假设、长期规则和讨论档案。
- 每次观影可录入片名、时间点和具体观察；有模型接口时由 AI 归类，离线时由本地术语权重匹配，并挂到现有节点或生长为个人新节点。
- 可连接 OpenAI-compatible Chat Completions 接口进行实时导师对谈；未配置时提供本地结构化追问。

## 关于视频大小与隐私

视频由浏览器读取本机文件，应用不会复制或上传原始视频。因此没有应用层上传大小限制；仍受设备内存、解码速度、视频长度和浏览器格式支持影响。刷新页面后需要重新选择原片，但镜头指标与时间线笔记会保留。

## Skill

同一训练方法还提供为 Codex Skill：`$story-cutting-mentor`。在 Codex 中可以直接让它读取本地视频路径、生成接触表、进行版本对比，并把讨论沉入长期画像。
